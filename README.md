This regression machine learning project utilizes a used car dataset to predict the continuous variable of vehicle selling price. Notebook sections include exploratory data analysis, visualization EDA, and machine learning. Ridge and Gradient Boosting regression models are employed with the final model being chosen based on cross validation scoring. Regression metrics including R2, MSE, and MAE are calculated to determine final model performance. Finally, feature evaluation is completed to determine which data set features possessed the highest predictive power of the continuous target variable.
